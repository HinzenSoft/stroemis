HTML-Baustein: Rahmen im Artikel, Menü und Griffe im Editor

Prüft den HTML-Baustein in beiden Ansichten: Im Artikel entsteht aus der Bild-Schreibweise ein gesandboxter Rahmen mit den Maßen aus der Adresse; im Editor steckt er in einer Hülle mit Griff, bekommt dasselbe Menü wie ein Bild (Breite, Höhe, Ausrichtung, Titel …) und lässt sich an drei Griffen ziehen – rechts die Breite, unten die Höhe. Gespeichert wird in der Adresse (#w=…&h=…); geprüft wird, was der Editor an den Server schickt. Diese Datei direkt im Browser öffnen (Doppelklick) – der Server ist eine Attrappe, die jeden PUT sofort beantwortet und mitschreibt.
